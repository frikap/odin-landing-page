# Landing Page Project

A responsive landing page built from a design specification as part of [The Odin Project's Foundations Course](https://www.theodinproject.com/lessons/foundations-landing-page).

## 🚀 Overview

The goal of this project was to replicate a provided design mockup from scratch using semantic HTML and CSS Flexbox layout techniques.

## ✨ Features

- **Semantic HTML5 Structure:** Clean and well-organized markup.
- **CSS Flexbox:** Used across all sections for alignment, spacing, and layout distribution.
- **Modern Typography & Color Palette:** Integrated Google Fonts (`Roboto`) and precise color contrast matching the design specification.

## 🛠️ Built With

- **HTML5**
- **CSS3** (Flexbox)
- **Google Fonts** (Roboto)
